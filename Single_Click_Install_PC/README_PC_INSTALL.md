# 💻 1-Click Installation Guide for Windows PC

Follow these simple steps to install and run **FinTrack Pro** on your Windows PC with full offline persistence.

---

## ⚡ Quick 1-Click Setup

1. Make sure you have **[Node.js](https://nodejs.org/)** (v18 or v20 LTS) installed on your computer.
2. Open the `Single_Click_Install_PC` folder.
3. Double-click **`1-Click_Install_and_Launch_PC.bat`**.

### What this script does automatically:
- Installs all necessary packages and dependencies.
- Creates a **"FinTrack Pro (Offline)"** shortcut directly on your Windows Desktop.
- Boots the local offline server and opens the app in your default browser at `http://localhost:3000`.

---

## 🚀 Daily Use

For everyday use after initial setup:
- Simply double-click the **"FinTrack Pro (Offline)"** icon on your Desktop, OR
- Double-click **`Start_FinTrack_Pro.bat`** in this folder.

---

## 🔒 Privacy & Offline Capability
- All transactions, budgets, SIPs, and lend/borrow records are securely stored locally on your PC.
- No active internet connection is required to record expenses or view analytics.
